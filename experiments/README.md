# Experiments

This directory is the executable record behind Monday's FunctionalArbor branch of thought. The main README carries the interpretation; this file is only a compact experiment ledger.

All of these tests separate **representability** from **blind learning**. Most later experiments deliberately give the arbor a target demixing direction learned or defined elsewhere, then ask whether legal mass-conserving morphology can physically realize it.

## 1. FA-BSS0 — synthetic one-frequency capability

Question: can a fixed-mass FunctionalArbor reshape its geometry so the soma approximates one known source-extraction coefficient?

Main scripts:

- `fa_bss0_run.py`
- `fa_bss0_run_fast.py`
- `fa_bss0_reachability.py`
- `fa_bss0_transfer_selftest.py`

Typical run:

```bash
python experiments/fa_bss0_run_fast.py --fa-root ../FunctionalArbors --seeds 8 --mutations 28
```

Result: **capability yes, blind BSS not established.** Legal morphologies can reach useful complex transfer ratios. Reachability and learning/search are separate problems.

## 2. FA-BSS-REAL0 — real AuxIVA coefficient -> morphology

Input recording in `Wav/`:

- `two_ears_in0.wav` — microphone / XLR
- `two_ears_in1.wav` — guitar pickup / instrument input

Run:

```bash
python experiments/fa_bss_real0.py --fa-root ../FunctionalArbors
```

The script diagnoses the recording, fits digital references including AuxIVA, selects one genuinely complex AuxIVA demixing direction, then asks existing FunctionalArbor morphologies to approach it through legal structural changes.

Result: **3/4 seeds moved substantially closer to the selected AuxIVA direction; best projective error improved from about 39.8° to 16.1°.**

This is a compile / representability result, not blind source separation.

The exploratory one-bin fourth-cumulant learner is killed: it could increase non-Gaussianity while moving away from the candidate source.

Full result: [`../notes/fa_bss_real0_result.md`](../notes/fa_bss_real0_result.md)

## 3. FA-BSS-REAL1B — one real body, many frequencies

Run:

```bash
python experiments/fa_bss_real1b_broadband.py \
  --fa-root ../FunctionalArbors \
  --bins 9 --fmin 400 --fmax 2400 \
  --seeds 4 --steps 70 --oracle-steps 45
```

Question: can one shared morphology approximate a nine-frequency AuxIVA demixing curve?

Result:

```text
shared-body mean error: 43.64 -> 36.11 deg
best constant direction: 15.38 deg
representation_pass = false

held-out mean: 46.46 -> 42.10 deg
coupling_hint = true
```

The body moved several coefficients together, but the real target mostly collapsed toward one frequency-independent sensor direction. This killed the apparent broadband representation win while leaving a cross-frequency coupling hint.

Full result: [`../notes/fa_bss_real1b_result.md`](../notes/fa_bss_real1b_result.md)

## 4. FA-BSS-CONV0 — controlled rotating synthetic demixer

Run:

```bash
python experiments/fa_bss_conv0_rotating.py --fa-root ../FunctionalArbors
```

Frozen synthetic world:

```text
x1[t] = s1[t] + 0.90*s2[t-14]
x2[t] = 0.35*s1[t-3] + s2[t]

w(omega) = [1, -0.90 exp(-i14omega)]
```

This target was chosen before morphology ran and genuinely rotates across frequency.

Result:

```text
best constant direction: 31.38 deg
shared-body mean: 50.52 -> 33.33 deg
rotating_representation_pass = false   # only 2/4 beat constant

held-out mean: 49.88 -> 38.28 deg
median held-out improvement: 12.18 deg
heldout_coupling_pass = true
```

The exact matched FIR solves the target essentially perfectly and remains the boring calibration winner.

CONV0's useful residue is therefore narrow: **structural mutations selected on some frequencies can move unseen frequencies in a useful direction, and correct frequency ordering matters.**

Full result: [`../notes/fa_bss_conv0_result.md`](../notes/fa_bss_conv0_result.md)

## Reading the directory

The experiment sequence is intentionally a kill ladder:

```text
one coefficient is representable
        ↓
real complex coefficient is compilable
        ↓
one body moves several frequencies
        ↓
constant-vector attacker kills the apparent REAL1B win
        ↓
controlled rotating target removes that loophole
        ↓
shared morphology improves, but still does not reliably beat the constant model
        ↓
held-out cross-frequency coupling survives
```

That is where Monday stops for now.

Do not read these scripts as evidence that dendrites perform ICA or that FunctionalArbors is a practical source separator. The surviving experimental statement is about **coupled transfer functions generated by one persistent structure**.
